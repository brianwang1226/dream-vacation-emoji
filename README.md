A program that writes one emoji for the dream vacation: 🗻 Mount Fuji — snow on the peak, a red sun behind it, the one mountain every traveller pictures when they dream of Japan. It saves the emoji to /output/entry.txt for make.fun's judge to compare two at a time.

## Run it

```sh
node main.ts
```
